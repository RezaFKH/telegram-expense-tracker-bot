# 🤖 ربات تلگرامی مدیریت خرج ماهانه

باتی برای ثبت و پیگیری خرج‌های ماهانه با تقویم شمسی، واحد پول دلخواه و جداکنندهٔ ارقام `'` (هر سه رقم از راست: `1'234'567`).

## ✨ امکانات

| امکان | توضیح |
|---|---|
| ➕ ثبت سریع | یک پیام: `250000 کافه` (مبلغ + توضیح) |
| ➕ ثبت مرحله‌ای | مبلغ ← توضیح ← انتخاب دسته‌بندی |
| 🏷 دسته‌بندی | خوراک، حمل‌ونقل، قبوض، سرگرمی و… + تغییر دسته بعد از ثبت |
| 📊 گزارش ماهانه | جمع کل، تعداد، میانگین، تفکیک دسته‌ها با نمودار متنی و لیست کامل خریدها |
| ◀️ ▶️ ناوبری ماه | مرور گزارش هر ماه شمسی با دکمه‌های ماه قبل/بعد |
| 💰 جمع تا امروز | میزان خرج از اول ماه تا همین لحظه |
| 🛒 مدیریت خریدها | نمایش محصولات با قیمت ثبت‌شده + حذف با یک کلیک |
| ↩️ واگرد | حذف آخرین خرج با `/undo` |
| 📄 خروجی CSV | فایل سازگار با Excel؛ مثل `/export 1405/08` |
| 💱 واحد پول | در نخستین اجرا از کاربر پرسیده می‌شود و از تنظیمات قابل تغییر است |
| 📅 تقویم شمسی | همهٔ ماه‌ها و گزارش‌ها بر پایهٔ تقویم جلالی |
| 🗄 بدون سرویس خارجی | ذخیره‌سازی محلی با SQLite |
| 👥 پشتیبانی گروه | تنظیمات و داده‌ها به ازای هر چت (خصوصی یا گروهی) |

## 🚀 راه‌اندازی

### ۱) ساخت ربات در تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
2. دستور `/newbot` را بزنید و نام و نام‌کاربری ربات را انتخاب کنید.
3. توکن (شبیه `123456:ABC-DEF…`) را کپی کنید.

### ۲) نصب

```bash
git clone https://github.com/RezaFKH/telegram-expense-tracker-bot.git
cd telegram-expense-tracker-bot

python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# لینوکس/مک:
source .venv/bin/activate

pip install -r requirements.txt
```

### ۳) تنظیم توکن

```bash
cp .env.example .env
# سپس فایل .env را باز کنید و BOT_TOKEN را جایگزین کنید
```

### ۴) اجرا

```bash
python bot.py
```

همین! در تلگرام `/start` را بفرستید؛ ابتدا واحد پول پرسیده می‌شود و بعد می‌توانید خرج ثبت کنید.

> پیش‌نیاز: Python 3.10 یا جدیدتر

## 📖 نحوهٔ استفاده

```
250000 کافه            ← ثبت سریع (دسته پیش‌فرض: سایر)
250000                 ← فقط مبلغ؛ توضیح پرسیده می‌شود
1'250'000 اجاره خانه   ← جداکنندهٔ هزارگان آزاد است (' یا , یا ارقام فارسی)
```

| دستور | کار |
|---|---|
| `/start` | شروع و منوی اصلی |
| `/add` | ثبت خرج مرحله‌ای (`/add 250000 کافه` هم کار می‌کند) |
| `/report` | گزارش ماه جاری (ماه دیگر: `/report 1405/08`) |
| `/total` | جمع خرج این ماه تا امروز |
| `/items` | لیست خریدهای ماه با دکمهٔ حذف |
| `/undo` | حذف آخرین خرج |
| `/export` | خروجی CSV (`/export 1405/08`) |
| `/settings` | تغییر واحد پول، پاک‌کردن همهٔ داده‌ها |
| `/cancel` | لغو عملیات جاری |

## 🏗 ساختار پروژه

```
├── bot.py          # منطق ربات: دستورها، منوها، وضعیت گفتگو
├── database.py     # لایهٔ SQLite (settings و expenses)
├── utils.py        # تقویم شمسی، قالب‌بندی اعداد، پارس مبلغ
├── selftest.py     # تست‌های سریع (python selftest.py)
├── requirements.txt
├── .env.example    # نمونهٔ متغیرهای محیطی
└── .gitignore
```

## ⚙️ متغیرهای محیطی

| متغیر | الزامی | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات از @BotFather |
| `EXPENSES_DB` | ❌ | مسیر فایل دیتابیس (پیش‌فرض: `expenses.db` کنار `bot.py`) |

## 🖥 استقرار روی سرور (Linux + systemd)

```ini
# /etc/systemd/system/expense-bot.service
[Unit]
Description=Telegram Expense Tracker Bot
After=network-online.target

[Service]
WorkingDirectory=/opt/telegram-expense-tracker-bot
ExecStart=/opt/telegram-expense-tracker-bot/.venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now expense-bot
```

## 🔒 نکات امنیتی

- توکن ربات فقط در `.env` نگه داشته شود (در `.gitignore` هست و هرگز کامیت نمی‌شود).
- داده‌ها فقط در فایل SQLite محلی ذخیره می‌شوند؛ از پشتیبان‌گیری منظم `expenses.db` غافل نشوید.
- برای حذف دسته‌جمعی داده‌ها، در تنظیمات تأیید دومرحله‌ای وجود دارد.
